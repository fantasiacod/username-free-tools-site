About Code Engineer

Code Engineer is a small, independent collection of free online tools. The idea is simple: everyday tasks — generating a QR code, converting an image, compressing a file — shouldn't require an account, a subscription, or uploading your files to an unknown server.

Every tool here runs entirely in your browser using standard web technologies (the Canvas API, File API, and similar). Nothing you enter or upload is sent to a server, because there's no backend involved at all — the site is just static files.

New tools are added regularly. If there's a tool you'd like to see, get in touch on the contact page.
