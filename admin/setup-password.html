Generate Your Admin Password Hash

This page runs entirely in your browser — your password is never sent anywhere, not even to this site's own server. It computes a one-way hash (PBKDF2-SHA256, 210,000 iterations) of the password you choose, matching exactly what the login server checks against. Copy the resulting hash into your Vercel project's ADMIN_PASSWORD_HASH environment variable. This page is not linked from anywhere on the site — bookmark it if you'll need it again (e.g. to change your password later).

Copy this value into Vercel → your project → Settings → Environment Variables → ADMIN_PASSWORD_HASH:

You'll also need two more environment variables in Vercel, which don't depend on your password: a random SESSION_SECRET (any long random string — used to sign login sessions) and ADMIN_GITHUB_TOKEN (a fine-grained GitHub token scoped to this one repo with Contents: read/write, used by the panel to commit your changes).
