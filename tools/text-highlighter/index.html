How this text highlighter works

Type or paste text into the box, select any word or passage with your mouse or keyboard, then click a highlight color or a Bold/Underline/Strikethrough button to mark it — everything runs locally in your browser using standard text-editing commands, and nothing you type is uploaded anywhere. "Copy formatted" copies rich text that keeps its highlighting and styling when pasted into an email, Google Doc or Word document. "Copy as plain text" instead copies ordinary text using common markdown-style symbols (**bold**, __underline__, ~~strikethrough~~, ==highlight==) so the emphasis survives even in places that don't support rich text, like a code comment or a plain-text field.

When you'd use a text highlighter

This is handy for marking up notes or a draft before sharing it, highlighting the key sentence in a long paragraph you're pasting into an email, drawing attention to changes in feedback you're sending back to someone, or preparing text for a place that understands markdown-style emphasis. Because both a rich-text and a plain-text copy are available, the result works whether you're pasting into a document editor or a plain textbox.
