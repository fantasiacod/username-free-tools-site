HEX, RGB and HSL — what's the difference?

All three formats describe the exact same color, just with different numbers. HEX (like #4F8CFF) packs red, green and blue into a six-digit base-16 code — compact and the most common format in CSS and design tools. RGB (like rgb(79, 140, 255)) spells out the same red, green and blue channels as plain 0-255 numbers, which is easier to read and to tweak by hand. HSL (like hsl(215, 100%, 65%)) describes a color by Hue (its position on a 0-360° color wheel), Saturation (how vivid vs. gray it is) and Lightness (how close to black or white it is) — it's the most intuitive format for adjusting a color, since making something lighter, darker or more muted is a single number change instead of recalculating three separate channels.

When you'd use a color converter

Designers and developers constantly need to translate a color between these formats: a design tool like Figma or Photoshop hands you a HEX code, but you need the RGB values for a canvas/JS project, or you want to darken a brand color slightly and HSL's Lightness value makes that trivial compared to guessing new RGB numbers. This tool keeps all three formats in sync as you type or use the native color picker, so you can grab whichever format the CSS, code, or design software you're working in actually expects.
