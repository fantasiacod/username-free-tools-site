Password Generator

Create a strong, random password with the length and character options below. Everything happens locally in your browser using the Web Crypto API — your generated password is never sent anywhere.

Passwords are generated using your browser's cryptographically secure random number generator (Web Crypto API), not a predictable Math.random() sequence. Nothing is stored or transmitted.

How this password generator works

This tool builds a password by picking random characters from the character sets you enable (uppercase letters, lowercase letters, numbers and symbols) using crypto.getRandomValues(), the same cryptographically secure randomness source browsers use for security-sensitive operations. That makes the result far less predictable than passwords generated with a simple pseudo-random function, and since it all runs on your device, the password is never transmitted to a server or logged anywhere.

Tips for stronger passwords

Longer is generally stronger: aim for at least 12-16 characters, and use all four character sets when the site you're signing up for allows it. Avoid reusing the same password across multiple accounts — if one site is breached, reused passwords put every other account at risk too. A password manager can store unique, random passwords like the ones this tool generates so you don't have to remember them yourself.
