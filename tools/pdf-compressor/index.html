How this PDF compressor works

This tool loads your PDF using pdf-lib, an open-source library running entirely in your browser. It strips metadata that many PDF creation tools embed (author, title, producer software, timestamps), recompresses eligible embedded JPEG images at a slightly reduced quality to shrink them further, and re-saves the file using compact cross-reference object streams instead of the older, more verbose PDF format. Every compressed file is automatically checked before it's offered for download, and if anything looks off the tool falls back to a metadata-only version instead — so you never end up with a broken file. Nothing is uploaded to a server at any point.

Tips for smaller PDF files

The biggest driver of PDF file size is usually embedded images. If your PDF is still too large after compressing it here, try re-exporting it at a lower image resolution or JPEG quality from the original source application before compressing, or shrink any images with this site's Image Converter & Compressor before placing them in the document. Scanned documents saved as high-resolution images are the most common cause of oversized PDFs.
