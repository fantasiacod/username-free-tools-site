How this image resizer works

The tool draws your image onto an HTML canvas at the exact width and height you set, then re-encodes it using your browser's built-in image codecs — the same technology browsers use to render images on the web. With aspect ratio locked, changing the width automatically recalculates the height (and vice versa) so the image never looks stretched. Nothing is uploaded to a server at any point.

When to resize an image

Resizing to the exact dimensions a site or form requires — a profile photo, a product image, a banner — keeps pages loading fast and avoids images being auto-scaled (and often blurred) by the platform you're uploading to. For photos you plan to compress further after resizing, this site's Image Converter & Compressor can also adjust format and quality.
