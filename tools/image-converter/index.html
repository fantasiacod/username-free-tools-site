How it works

The tool loads your image into an HTML canvas and re-encodes it using your browser's built-in image codecs — the same technology browsers use to render images on the web. Nothing is uploaded to a server at any point.

When to use JPEG vs WebP vs PNG

Use JPEG for photos where small file size matters most. Use WebP for a modern format that's usually smaller than JPEG at the same quality. Use PNG when you need transparency or lossless quality, such as for logos and screenshots with text.
